# Devdatth | Futuristic 3D Developer Portfolio & Digital OS

An award-winning, interactive 3D developer portfolio and system OS engineered for **Devdatth**, an AI & Data Science Engineer, Full Stack Developer, and Creative Developer based in Pune, India.

---

## ⚡ Key Highlights & Architecture

- **Custom Three.js 3D Engine**: Holographic particle neural entity, dynamic facial geometry, orbital quantum rings, mouse reaction, particle distortion, and section-by-section geometric morphing.
- **Futuristic HUD & Glass Interface**: Near-black aesthetic (`#050505`), animated cyber grids, technical telemetry status panels, monospace typography, and interactive scanning effects.
- **Dynamic Floating Menu**: Glass navigation dock with quick social pills (LinkedIn, GitHub, Resume, Email), Dev Labs launcher, and seamless section jump.
- **Global System Config (Settings Panel)**:
  - **Core Themes**: 5 dynamic colorways (*White/Monochrome, Cyan Neon, Matrix Green, Solar Amber, Crimson Red*) syncing CSS variables and Three.js 3D particles in real time.
  - **Audio Engine**: Pure browser Web Audio API oscillator synthesizer with zero external assets (Ambient Lo-Fi Drone, Digital Minimalism pulse, hover and click soundscapes).
  - **Performance Tiers**: *High*, *Medium*, and *Saver* (auto-adjusting particle counts and rendering fidelity).
- **Featured Technical Projects**:
  1. **AgentForge**: Modular AI Agent framework with tool registries and reflection loops.
  2. **Project Dynamo**: Scalable ML infrastructure, hyperparameter sweeps, and evaluation pipelines.
  3. **AI Agriculture Assistant**: Agritech AI advisory platform built with Django.
  4. **Milk Collection Management System**: High-throughput Java Swing and MySQL cooperative dairy billing engine.
- **Interactive Dev Labs**: Live AI Agent execution simulator, Neural weight & activation matrix playground, and system diagnostics.
- **Quantum Transmission Console**: Interactive contact form with input validation, simulation status, and copyable email utilities.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Devdatth/portfolio.git

# Navigate into the project folder
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The app will be accessible at `http://localhost:3000`.

## 🚢 Deploying to Vercel

This portfolio is production-ready for deployment on [Vercel](https://vercel.com).

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "feat: initial release of futuristic 3d portfolio"
git branch -M main
git remote add origin https://github.com/Devdatth/portfolio.git
git push -u origin main
```

### Step 2: Import on Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and select your `portfolio` repository.
3. Build Settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
